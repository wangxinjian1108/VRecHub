# sam3-train Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ghcr.io/wangxinjian1108/sam3-train` (runtime + dev), a layered image FROM `sam3:latest` adding sam3 `[train]` extras, with a CI workflow that fires after `Docker – sam3` succeeds.

**Architecture:** A two-line runtime Dockerfile (`FROM sam3:latest` + `cd /sam3 && pip install -e ".[train]"`) inherits everything (CUDA, conda env, sam3 source, weights, flash-attn-3) from the upstream image. A paired Dockerfile.dev clones the existing s6+SSH+JupyterLab template. CI runs via `workflow_run` after the upstream `Docker – sam3` workflow completes successfully, with manual `workflow_dispatch` and path-trigger backstops.

**Tech Stack:** Docker (buildx, BuildKit), GitHub Actions (workflow_run trigger), `actions/checkout@v4`, `docker/build-push-action@v6`.

## Global Constraints

- Image path: `docker/sam3-train/`
- Image name: `ghcr.io/wangxinjian1108/sam3-train` + Docker Hub mirror via `${{ secrets.DOCKERHUB_USERNAME }}/sam3-train`
- Base for runtime: `ghcr.io/wangxinjian1108/sam3:latest` (overridable via `ARG BASE_IMAGE`)
- Base for dev: `ghcr.io/wangxinjian1108/sam3-train:latest` (overridable via `ARG BASE_IMAGE`)
- Runtime tags: `latest`, `sha-<7>`, `<branch>`, `v*.*.*`. Dev tags: `dev`, `dev-sha-<7>`

- Dev image: s6-overlay v3.2.0.2 + SSH(:22) + JupyterLab(:8888) + jovyan UID=1000 GID=100 + root password `ShARC`
- New extras to install on top of base: sam3 `[train]` (hydra-core, submitit, tensorboard, zstandard, scipy, torchmetrics, fvcore, fairscale, scikit-image, scikit-learn)
- No HF token needed for runtime build (weights are inherited from base)
- No submodule init in workflow (image does not COPY any thirdparty source)

### Task 1: Runtime Dockerfile

**Files:**
- Create: `docker/sam3-train/Dockerfile`

**Interfaces:**
- Consumes: `${BASE_IMAGE}` build-arg defaulting to `ghcr.io/wangxinjian1108/sam3:latest`. The base image carries CUDA 12.8.1, Python 3.12 conda env named `sam3` with sam3 editable-installed at `/sam3` (the upstream `docker/sam3/Dockerfile` uses `WORKDIR /sam3` + `COPY thirdparty/sam3 .`) plus the `[notebooks]` extras and flash-attn-3, weights at `/opt/var/models/sam3`, root SSH host keys, and a `${CONDA_DIR}/bin` PATH. The `conda` binary is on PATH; `${CONDA_DIR}` resolves to `/opt/conda`.
- Produces: `ghcr.io/wangxinjian1108/sam3-train:latest` — same as base plus the 10 `[train]` extras packages installed into the `sam3` conda env. CMD reset to `/bin/bash`. Used as base by Task 2 and as the runtime tag pulled by Task 4 dev build.

The runtime image is intentionally minimal: a single `pip install` layer adds the train extras. `cd /sam3 && pip install -e ".[train]"` is the form pip accepts — `pip install <abs-path>[extra]` (with or without `-e`) is rejected by pip. This matches the upstream `docker/sam3/Dockerfile` install pattern. The CMD is reset to `/bin/bash` (matching the upstream sam3 image, which sets the same).

- [ ] **Step 1: Create the directory and Dockerfile**

Create `docker/sam3-train/Dockerfile`:

```dockerfile
ARG BASE_IMAGE=ghcr.io/wangxinjian1108/sam3:latest
FROM ${BASE_IMAGE}

# Add sam3 [train] extras on top of the inherited [notebooks] install:
#   hydra-core, submitit, tensorboard, zstandard, scipy,
#   torchmetrics, fvcore, fairscale, scikit-image, scikit-learn
RUN cd /sam3 && conda run -n sam3 pip install --no-cache-dir -e ".[train]"

CMD ["/bin/bash"]
```

### Task 3: GitHub Actions workflow

**Files:**
- Create: `.github/workflows/docker-sam3-train.yml`

**Interfaces:**
- Consumes: secrets `GITHUB_TOKEN` (always), optional `DOCKERHUB_USERNAME` + `DOCKERHUB_TOKEN`. Triggered automatically when the workflow named `Docker – sam3` (defined in `.github/workflows/docker-sam3.yml`) completes successfully on `master`. Also triggers on direct push/PR to `docker/sam3-train/**` and the workflow file itself, plus manual `workflow_dispatch`.
- Produces: pushes `ghcr.io/wangxinjian1108/sam3-train:{latest,sha-<7>,<branch>}` and `:{dev,dev-sha-<7>}` on master. On PRs, builds without pushing.

The `workflow_run` trigger fires regardless of upstream conclusion; the `if:` guard on the job ensures we only build after a successful upstream run. Path triggers exclude `thirdparty/sam3` because source-code changes flow through `docker-sam3.yml` first and reach us via the workflow_run chain.

- [ ] **Step 1: Create the workflow file**

Create `.github/workflows/docker-sam3-train.yml`:

```yaml
name: Docker – sam3-train

on:
  workflow_run:
    workflows: ["Docker – sam3"]
    types: [completed]
    branches: [master]
  push:
    branches: [master]
    tags: ["v*.*.*"]
    paths:
      - "docker/sam3-train/**"
      - ".github/workflows/docker-sam3-train.yml"
  pull_request:
    branches: [master]
    paths:
      - "docker/sam3-train/**"
      - ".github/workflows/docker-sam3-train.yml"
  workflow_dispatch:

jobs:
  build-and-push:
    if: ${{ github.event_name != 'workflow_run' || github.event.workflow_run.conclusion == 'success' }}
    runs-on: ubuntu-latest
    permissions:
      contents: read
      packages: write
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Free disk space
        run: |
          sudo rm -rf /usr/share/dotnet /usr/local/lib/android /opt/ghc /opt/hostedtoolcache
          sudo rm -rf /usr/share/swift /usr/local/graalvm /usr/local/.ghcup
          sudo rm -rf /usr/local/share/powershell /usr/local/share/chromium
          sudo docker image prune -af
          df -h

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Login to Docker Hub
        if: github.event_name != 'pull_request' && env.DOCKERHUB_USERNAME != ''
        env:
          DOCKERHUB_USERNAME: ${{ secrets.DOCKERHUB_USERNAME }}
        uses: docker/login-action@v3
        with:
          username: ${{ secrets.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}

      - name: Login to GHCR
        if: github.event_name != 'pull_request'
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.repository_owner }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Docker metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: |
            name=${{ secrets.DOCKERHUB_USERNAME }}/sam3-train,enable=${{ secrets.DOCKERHUB_USERNAME != '' }}
            ghcr.io/${{ github.repository_owner }}/sam3-train
          tags: |
            type=ref,event=branch
            type=semver,pattern={{version}}
            type=semver,pattern={{major}}.{{minor}}
            type=sha,prefix=sha-,format=short
            type=raw,value=latest,enable={{is_default_branch}}

      - name: Set runtime base tag for dev image
        id: runtime-base
        run: |
          echo "remote=ghcr.io/${{ github.repository_owner }}/sam3-train:sha-${GITHUB_SHA::7}" >> "$GITHUB_OUTPUT"

      - name: Build runtime image
        uses: docker/build-push-action@v6
        with:
          context: .
          file: docker/sam3-train/Dockerfile
          push: ${{ github.event_name != 'pull_request' }}
          tags: |
            ${{ steps.meta.outputs.tags }}
            ${{ steps.runtime-base.outputs.remote }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha
          cache-to: type=gha,mode=max

      - name: Docker metadata for dev image
        id: meta-dev
        uses: docker/metadata-action@v5
        with:
          images: |
            name=${{ secrets.DOCKERHUB_USERNAME }}/sam3-train,enable=${{ secrets.DOCKERHUB_USERNAME != '' }}
            ghcr.io/${{ github.repository_owner }}/sam3-train
          tags: |
            type=raw,value=dev
            type=sha,prefix=dev-sha-,format=short

      - name: Build dev image
        if: github.event_name != 'pull_request'
        uses: docker/build-push-action@v6
        with:
          context: .
          file: docker/sam3-train/Dockerfile.dev
          push: true
          build-args: |
            BASE_IMAGE=${{ steps.runtime-base.outputs.remote }}
          tags: ${{ steps.meta-dev.outputs.tags }}
          labels: ${{ steps.meta-dev.outputs.labels }}
          cache-from: type=gha,scope=dev
          cache-to: type=gha,mode=max,scope=dev
```

- [ ] **Step 4: On failure — diagnose and pick fallback**

Common failure modes for this image:

| Symptom | Likely cause | Response |
|---|---|---|
| `pip install` fails to resolve a dep | Version conflict with already-installed `[notebooks]` extras (e.g. shared scikit-image / scikit-learn) | Pin the conflicting package explicitly in the same pip line |
| pip rejects `<path>[train]` syntax | pip parses `[...]` as path glob unless invoked with `cd <path>` + `pip install -e ".[train]"` | Use the `cd /sam3 && pip install -e ".[train]"` form (matches upstream `docker/sam3/Dockerfile`) |
| Workflow does not trigger after pushing | `paths` filter too narrow or wrong filename | Confirm `paths` includes `docker/sam3-train/**` |
| Job runs but immediately exits | `if:` guard rejected the event | Inspect `gh run view <id>` — `workflow_run` from a failed upstream is the most common cause |
